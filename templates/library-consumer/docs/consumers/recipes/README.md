# Integration recipes

Add focused Markdown recipes for supported integration tasks, and reference them from [catalog.json](../catalog.json). Keep each recipe tied to the package version or range actually exercised.

A useful recipe identifies the application need, owning APIs, dependencies and registration/configuration, application adapter responsibilities, failure/lifetime behavior, and validation commands or acceptance steps. Include a small working example when it clarifies the integration. Link version compatibility notes when signatures or defaults differ.

Keep links relative to the consumer documentation tree so recipes remain usable inside an extracted plugin. Language-specific compile checks can be added by the library; this generic scaffold does not claim that prose examples compile.
