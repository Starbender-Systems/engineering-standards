# General engineering

<!-- authority: standard.general -->

## Purpose and scope

All engineering changes and agent tasks.

## Rules

- MUST inspect repository instructions, existing behavior, and uncommitted changes before editing; preserve unrelated work.
- MUST keep changes within the task's scope and make assumptions and unresolved conflicts visible.
- MUST use MUST for requirements, SHOULD for defaults with justified exceptions, and MAY for optional guidance.
- MUST distinguish observed results from inference and report validation that could not run.

## Exceptions and escalation

Record the reason, affected scope, and validation for an exception in the change. Escalate unresolved conflicts to the repository maintainer using the repository's existing review process.
